# Purplease website

Revamp of [purplease.com](https://purplease.com), a WordPress site running the Astra theme with an Astra child theme, Spectra (Ultimate Addons for Gutenberg), Contact Form 7 and Rank Math.

## Layout

```
docs/                     audit (full-audit-2026-10-28.md), plan and screenshots
wp-content/themes/        Astra child theme (add once exported from the live site)
```

Only version the child theme and any custom plugins here. WordPress core, third-party plugins, uploads and `wp-config.php` stay out of git (see `.gitignore`).
